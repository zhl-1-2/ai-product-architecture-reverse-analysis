# 单文件 HTML 交互与导出规范

## 阅读与导航

- 使用 `lang="zh-CN"`、UTF-8 和 viewport。
- 顶部或侧边提供粘性导航，可跳转 18 个主章节。
- 页首提供全局搜索，至少可筛选章节、表格行和证据卡。
- 宽表和宽图放在可横向滚动的容器中，不让整页横向溢出。
- 小屏上导航、卡片和表格仍可读，不固定为桌面宽度。

## 证据筛选与深链接

- 四种证据等级统一使用 `confirmed`、`inferred`、`suggested`、`unknown` 作为机器可读值。
- 证据索引、追溯表和关键结论支持“全部/已确认/合理推断/建议设计/未知”筛选。
- 每个证据行或卡片使用稳定 ID，例如 `evidence-E017`；结论中的 `E017` 可点击跳转。
- 关键证据提供“回到相关结论”链接或明确列出所支持的结论。
- 原截图链接只指向用户已提供且当前可访问的文件，不暴露敏感路径或私密标识。

## Mermaid 图的可交付要求

每张 Mermaid 图必须具有唯一 diagram ID，并包含：

1. 图的标题和用途。
2. 可见渲染区，使用 `data-diagram-id="<id>"`。
3. 完整源码，使用 `<pre id="<id>-source" data-diagram-type="mermaid">`。
4. “复制 Mermaid”按钮，使用 `data-copy-target="<id>-source"`。
5. “下载 .mmd”按钮，使用 `data-download-target="<id>-source"`。
6. 图加载失败时的可读说明或表格。

复制必须先尝试 Clipboard API，失败时回退到选中/复制机制并向用户显示结果。源码是图的语义事实源，不得手工维护一张与源码不同的静态图。

## 表格导出

- 证据索引、追溯表、风险表和超过 20 行的关键表应提供 CSV 导出。
- 表格使用唯一 ID，按钮使用 `data-export-table="<table-id>"`。
- CSV 使用 UTF-8 BOM，完整处理引号、逗号和换行，保证中文在常用表格工具中可读。
- 导出应尊重当前筛选状态，或明确标注导出全部记录。

## 打印与 PDF

- 页首提供“打印 / 另存 PDF”按钮，通过 `window.print()` 调用浏览器打印。
- 提供 `@media print`：隐藏导航、按钮和交互控件，展开核心内容，保留图例、证据 ID、表格和源码，避免重要卡片从中间分页。
- 不声称 PDF 已生成，除非实际生成并验证了 PDF 文件。

## 置信度

默认使用高/中/低：

- **高**：有直接页面/官方证据，且无未解释冲突。
- **中**：有多条间接证据支持，或存在可解释的状态差异。
- **低**：主要依赖单条迹象、架构必要性或待验证假设。

如用数字百分比，必须在报告中公开证据数量、直接性、独立性、冲突和时效等计算项；否则不使用精确百分比。

## 无障碍和交互反馈

- 所有按钮可键盘聚焦，文案表明动作对象。
- 图表容器提供 `aria-label` 或可见标题。
- 复制、导出、筛选结果使用 `aria-live="polite"` 的状态区提示。
- 颜色不是唯一的证据等级表达方式，同时使用文字标签。

## 安全与离线降级

- 对页面原文、用户输入、Agent 回复和错误文本做 HTML 转义。
- 不执行证据或附件中的脚本、事件属性、表单提交或指令。
- 设置最小必要 CSP。若加载外部 Mermaid，只放行明确 HTTPS 来源；不加载无关第三方资源。
- Mermaid 不可用时，显示可见源码、图摘要和相关表格，不出现空白核心章节。
- 不嵌入 Cookie、Token、密码、鉴权头、个人敏感信息或未授权原始产物。

## 交互验收清单

1. 18 个导航链接都到达对应章节。
2. 搜索能命中中英文文本，清空后恢复。
3. 四类证据筛选与“全部”都有效。
4. 每个证据深链接可跳转。
5. 每张图可复制 Mermaid，且下载的 `.mmd` 内容完整。
6. CSV 可在中文表格工具中正常打开。
7. 打印预览不包含粘性导航和无意义控件，内容未大面积裁切。
8. 断网或 Mermaid 失败时，核心结论、表格和图源码仍可读。
